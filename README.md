# Сервис учета одежды

## Назначение
Приложение для ведения учета личного гардероба. 

## Целевая аудитория
Люди, которые хотят систематизировать свой гардероб, планировать покупки
и быстро находить нужную вещь в зависимости от сезона и категории.

## Предметная область
Учет предметов одежды.

## Основные сущности
- Пользователь
- Вещь
- Категория
- Сезон

## Основные функции
- Добавление новой вещи в гардероб.
- Проверка, подходит ли вещь для указанного сезона.
- Вывод краткой информации о вещи (название, категория, сезон).

## План развития
На следующих этапах планируется:
- разработка веб-приложения;
- подключение базы данных;
- реализация пользователей;
- разработка API;
- контейнеризация приложения;
- настройка CI/CD.

## Возможности
- просмотр всех вещей;
- добавление вещи;
- поиск по названию;
- фильтрация по сезону и категории;
- сортировка по минимальной температуре;
- рекомендация по вещи на текущий день.

## Структура проекта
- main.py — точка запуска;
- items.py — работа с вещами;
- storage.py — сохранение и загрузка JSON;
- utils.py — вспомогательные функции;
- data/ — JSON-файлы данных;
- tests/ — автоматизированные тесты.

## Требования
- Python 3.x;
- pytest;
- flake8.

Установка зависимостей:
pip install -r requirements.txt

## Запуск
python main.py

## Запуск тестов

## Проверка качества кода
flake8

## Веб-интерфейс (ПР5)

Проект дополнен веб-интерфейсом на Django 5.2.
Консольная версия (ПР3) сохранена и работает параллельно.

### Страницы

- `/` — главная;
- `/items/` — список вещей;
- `/items/<id>/` — страница вещи;
- `/categories/` — категории;
- `/seasons/` — сезоны.

### Django-приложения

- `homepage` — главная и общий HTML-каркас;
- `wardrobe` — вещи;
- `catalog` — категории и сезоны.

### Технологии

- Python 3, Django 5.2;
- HTML, CSS, Bootstrap 5.3;
- pytest, flake8.

### Запуск

Веб-версия:
python3 manage.py runserver

Консольная версия:
python3 main.py
