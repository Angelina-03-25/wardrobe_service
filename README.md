# Сервис учета одежды

## Назначение
Приложение для ведения учета личного гардероба. Позволяет пользователю
добавлять вещи, распределять их по категориям и сезонам, а также
получать информацию о доступности вещей для носки в текущем сезоне.

## Целевая аудитория
Люди, которые хотят систематизировать свой гардероб, планировать покупки
и быстро находить нужную вещь в зависимости от сезона и категории.

## Предметная область
Учет предметов одежды. Каждая вещь относится к определенной категории
(например, «верхняя одежда», «обувь», «аксессуары») и сезону
(лето, зима, демисезон, всесезон). Пользователь владеет множеством вещей.

## Основные сущности
- Пользователь
- Вещь
- Категория
- Сезон

## Основные функции
- Добавление новой вещи в гардероб.
- Проверка, подходит ли вещь для указанного сезона.
- Вывод краткой информации о вещи (название, категория, сезон).

## План развития
На следующих этапах планируется:
- разработка веб-приложения;
- подключение базы данных;
- реализация пользователей;
- разработка API;
- контейнеризация приложения;
- настройка CI/CD.
